03 / MODEL REGULARIZATION

Understanding C

C is the inverse regularization-strength parameter in Logistic Regression.

INTERACTIVE C CONTROL
0.3
Regularization parameter
Move the slider to change C.
0.001 · Stronger 100 · Weaker
REGULARIZATION STRENGTH
Moderate regularization

The bar represents the inverse relationship conceptually, not an exact numerical penalty.

WHAT HAPPENS?
Small C More constrained

Stronger penalty on large coefficients. The model has less freedom.

Large C Less constrained

Weaker penalty on large coefficients. The model has more freedom.

At C = 0.3, the model applies regularization to control the magnitude of its coefficients.
Mathematical intuition: C is inversely related to regularization strength. Smaller C means stronger regularization; larger C means weaker regularization. This does not guarantee underfitting or overfitting; those depend on the data and model.

06 / IMPLEMENTATION

Python implementation

A simplified representation of the actual pipeline configuration.

PYTHON · SCIKIT-LEARN 
# 1. Feature extraction
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression

vectorizer = TfidfVectorizer(
    ngram_range=(1, 2)
)

X_train = vectorizer.fit_transform(train_texts)
X_val = vectorizer.transform(val_texts)

# 2. Classification
model = LogisticRegression(
    C=0.3,
    max_iter=1000
)

model.fit(X_train, y_train)
Important: The code above uses rec_A's selected C as an example. The actual selected C must be supplied separately for each of the four models. Fit TF-IDF only on training data; transform validation and test data using the fitted vectorizer.
