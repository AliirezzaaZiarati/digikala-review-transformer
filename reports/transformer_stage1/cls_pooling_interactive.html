۵) How it differs from other pooling methods

Your model uses CLS Pooling. These methods are not interchangeable.

CLS / First-token

z = h₀

Only the vector at position zero is selected. This is your project’s method.

Mean Pooling

z = mean(h₁ … hₗ)

میانگین بردار Token‌ها؛ معمولاً Padding با attention mask کنار گذاشته می‌شود.

Max Pooling

zⱼ = maxᵢ hᵢⱼ

برای هر بُعد، بزرگ‌ترین مقدار در بین Token‌ها انتخاب می‌شود.

۶) Walk through the code

# Encoder: one vector per token hidden = self.encoder(input_ids=input_ids, attention_mask=attention_mask).last_hidden_state # Select token at position 0 from every sequence features = self.dropout(hidden[:, 0]) # Same pooled representation feeds both task heads return {head: layer(features).float() for head, layer in self.heads.items()}

`hidden[:, 0]` This means: for every sequence in the batch, select only position zero. In the actual code, `FEATURE_POSITION = 0` is used instead of the literal 0, making the position a named constant. Dropout is applied after pooling; pooling itself has no trainable parameters.
